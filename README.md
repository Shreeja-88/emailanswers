# EmailAnswers

A React-based landing page for EmailAnswers, built with Vite.

## Project Structure

```text
emailanswers/
└── emailanswers-home/
    ├── src/
    │   ├── components/
    │   ├── App.jsx
    │   └── main.jsx
    ├── index.html
    ├── package.json
    └── vite.config.js
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Shreeja-88/emailanswers.git
cd emailanswers/emailanswers-home
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.
